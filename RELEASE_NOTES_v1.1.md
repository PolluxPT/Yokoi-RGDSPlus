# Yokoi RGDS+ Edition v1.1

## English

Standalone Linux ARM64 port for Anbernic RGDS+ Stock OS, based on
[RetroValou's Yokoi](https://github.com/RetroValou/Yokoi_Game_-_Watch_emulator_3ds).

- PT/EN blue interface, larger compact Pause menu and corrected action labels.
- Touch browsing, controller calibration and advanced options.
- Three save-state slots per game, slot management and exit/delete confirmation.
- Lower-screen full-size console image; L1/R1 jumps and L2/R2 screen swap.
- Volume control with smooth low steps and reduced menu-startup work.

**No ROMs, game packs or original game artwork are included.**
Build your own **Android (RGDS)** pack using the
[original CONVERT_ROM instructions](https://github.com/RetroValou/Yokoi_Game_-_Watch_emulator_3ds/blob/main/CONVERT_ROM/README.md#android-rgds),
then copy `yokoi_pack_rgds.ykp` to `Roms/APPS/Yokoi_RGDSPlus/`.
The 3DS pack is not compatible with this Linux port.

**This is an update for existing working installations.** Copy `Roms` to the
SD-card root and keep your existing runtime libraries, pack, settings and saves.
The required ARM64 runtime libraries are not included. Source code and build
instructions are available in this repository.


## Português

Adaptação standalone Linux ARM64 para Anbernic RGDS+ Stock OS, baseada no
[Yokoi de RetroValou](https://github.com/RetroValou/Yokoi_Game_-_Watch_emulator_3ds).

- Interface PT/EN e menus azuis; Pausa maior, compacta e com textos corrigidos.
- Touch, calibração dos botões e opções avançadas.
- Três slots por jogo, gestão de estados e confirmação para apagar/sair.
- Imagem do jogo no ecrã inferior; saltos L1/R1 e troca de ecrãs L2/R2.
- Volume com curva suave e arranque do menu otimizado.

**Sem ROMs, packs de jogos ou artwork original dos jogos.** Criar o seu próprio
pack **Android (RGDS)** através do [guia original CONVERT_ROM](https://github.com/RetroValou/Yokoi_Game_-_Watch_emulator_3ds/blob/main/CONVERT_ROM/README.md#android-rgds) e copiar
`yokoi_pack_rgds.ykp` para `Roms/APPS/Yokoi_RGDSPlus/`. O pack 3DS não é compatível.

**Atualização para instalações já funcionais.** Copiar `Roms` para a raiz do
cartão, conservando bibliotecas, pack, configurações e saves. As bibliotecas
ARM64 necessárias não estão incluídas. Código e instruções de compilação
constam do repositório.
